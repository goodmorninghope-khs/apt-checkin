# 아파트 체크인 · AI 파트너즈 QR 출결 시연판

중랑구 AI혁신팀 **AI 파트너즈(일명 아파트)** 과정(2026-11-05 시작)용 QR 출결 시연 사이트입니다.
출석을 '찍는' 게 아니라, 출석이 수업을 '시작'하게 만드는 사내 교육 AX 시연입니다.

## 흐름
1. **입실 QR**: 20초마다 바뀌어 캡처·단톡방 공유 QR은 자동 만료
2. **한 줄 질문**: 출석과 동시에 오늘의 고민 수집
3. **AI 라이브 브리핑**: 응답을 묶어 수업 첫 10분에 사용
4. **퇴실 QR**: 배운 것 1 + 7일 미션 1
5. **다음 회차**: "지난 미션 해 보셨어요?"로 체크인 시작
6. **운영 대시보드**: 출석부(수기 보정·CSV), 회차 보고 초안, AI 요청문, 챙김(안부) 알림

## 화면 주소
- `#/` 홈 · `#/screen` 강의장 화면 · `#/in?demo=1` 휴대폰 체크인 미리보기 · `#/admin` 운영 대시보드 · `#/guide` 도입 안내

## 시연판의 한계
- 기록은 브라우저 localStorage에만 저장(같은 브라우저 탭끼리만 실시간 연동).
- 토큰 검증은 브라우저 안에서 동작(구조 시연용). 실제 운영은 서버 서명 토큰 + 서버 저장소로 옮길 것.
- AI 브리핑은 규칙 기반. 실제 운영판에서 LLM 연결.
- 명단(24명)과 일정(목요일 6회)은 가상 예시.
